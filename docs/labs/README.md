# MeaningWire Labs

MeaningWire Labs is the project space for frontier ideas that are worth investigating but are not yet part of the stable contract surface.

## Purpose

Labs lets the project explore new standards, agent patterns, semantic techniques, interoperability tooling, and implementation approaches without implying production support.

## Maturity states

- `DISCOVERED` — potentially relevant idea identified.
- `RESEARCH` — evidence and prior art are being gathered.
- `EVALUATED` — tradeoffs have been documented well enough for a project decision.
- `EXPERIMENTAL` — implementation or executable exploration exists, with no compatibility promise.
- `PREVIEW` — intentionally exposed for broader use and feedback with documented limitations.
- `STABLE` — governed public contract with defined compatibility expectations.
- `REJECTED` — evaluated and intentionally not pursued.
- `SUPERSEDED` — replaced by a better approach.
- `DEPRECATED` — previously supported approach being retired.

## Rules

- Labs status must be visible in documentation and code.
- Experimental results must not be described as stable capabilities.
- A new idea does not bypass normal RFC, security, compatibility, or provenance review when it moves toward the public contract surface.
- Research should record sources and competing approaches rather than presenting novelty as proof of value.
