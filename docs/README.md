# MeaningWire Documentation

This directory contains project documentation that should be understandable without access to any private downstream repository.

Current areas:

- [`architecture/`](architecture/) — architectural principles and boundaries
- [`rfcs/`](rfcs/) — substantial public-contract and governance proposals
- [`labs/`](labs/) — explicitly experimental research and frontier concepts

Planned documentation work includes beginner guides, builder references, standards crosswalks, mapping examples, provenance explanations, accessibility guidance, and eventually a dedicated documentation site after the repository foundations are stable enough to justify one.
