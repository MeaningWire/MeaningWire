# Mappings

This directory will contain versioned mappings and crosswalks between external system concepts and MeaningWire canonical contracts.

MeaningWire intends to classify mapping relationships explicitly rather than treating every transform as equivalent.

Planned relationship vocabulary:

- `exact`
- `equivalent`
- `broader`
- `narrower`
- `derived`
- `transformed`
- `lossy`
- `unsupported`

Mappings should preserve provenance, identify source and target contract versions, document transformation rules, and make known loss or ambiguity visible.
