---
title: Pre-release status
description: What the current documentation source does and does not represent.
---

MeaningWire's documentation source is public before the first public versioned release so its implementation and evidence can be inspected as they develop.

A successful static documentation build means the source experience is reproducible for the governed toolchain. It does **not** mean the site has been deployed, the project is production-ready, compatibility is stable, or publication has been authorized.
