MeaningWire is a vendor-neutral semantic interoperability framework for defining shared meaning once and mapping systems at the edges.

## Current status

MeaningWire is in **quiet pre-release** development. The public repository is available for inspection and reproducible evaluation, but no public versioned release has been published yet.

The current experimental baseline includes canonical semantic primitives, an Identity / Party contract, mapping definitions and execution, read-only reference adapters, a CLI, provenance and authority boundaries, deterministic validation, candidate build evidence, and a non-publishing release-readiness gate.
