# Schemas

This directory will contain MeaningWire canonical schemas and related semantic contracts.

Planned requirements include:

- vendor-independent identifiers;
- explicit versioning;
- machine-readable JSON Schema representations;
- provenance and authority metadata where applicable;
- domain boundaries that do not import any one external standard wholesale;
- deterministic validation fixtures;
- documented compatibility and deprecation rules before stable release.

Initial domain families are planned for Identity / Parties, Products / Services, Commerce, Finance, Operations, Communications, Content, Governance, and Integration.

Schema design is not yet stable. Substantial semantic changes should use the RFC process.
